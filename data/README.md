# Datasets Directory

This directory contains the 5 evaluation datasets used by InsightForge.

**Note:** Dataset files (`.csv`, `.xlsx`) are gitignored to keep the repo lightweight.
Download instructions are in the main README.

## Datasets
1. `titanic.csv` — Titanic passenger data (Kaggle)
2. `superstore.csv` — Retail sales data
3. `ecommerce.csv` — E-commerce transactions
4. `ipl.csv` — IPL ball-by-ball cricket data
5. `synthetic_anomaly.csv` — Synthetic dataset with injected outliers
